# Cairn Linux trademark policy

This policy explains how the Cairn Linux project name and marks may be used.
It is separate from the copyright licences for the code, documentation, and
brand artwork.

## The marks and their owner

Mason Ball claims the following as project trademarks:

- the name **Cairn Linux**;
- **Cairn** when it identifies this operating-system project; and
- the stacked-stones mark in `brand/mark.svg` and its generated variants.

Mason is Cairn's founder and lead maintainer and may grant permission to use
the marks. Cairn Linux is not an incorporated organisation. This policy does
not represent that the marks are registered in any jurisdiction.

The SVG artwork is available under CC BY-SA 4.0. That copyright licence allows
copying and adaptation of the artwork, but it does not grant the right to use
the artwork as a mark for a product or service or to imply Cairn's endorsement.

This policy does not limit uses that applicable law allows without permission,
such as accurate referential use.

## Uses that do not require permission

You may:

- refer to Cairn Linux accurately in articles, reviews, discussions, and links;
- state that software works with Cairn Linux when that statement is accurate;
  and
- redistribute an unmodified official Cairn Linux release under its original
  name.

Do not imply that Cairn produced, sponsored, certified, or endorsed something
when it did not.

## Uses that require permission

Ask before you:

- name a modified build, fork, product, service, event, or organisation
  **Cairn Linux** or **Cairn**;
- use the stacked-stones mark to identify a modified build, commercial product,
  service, event, or organisation;
- register a domain, social account, package, application, or organisation
  name that could be mistaken for an official Cairn project property;
- sell merchandise carrying the name or mark; or
- claim certification, partnership, sponsorship, or endorsement by Cairn.

## Forks and modified distributions

The code licence permits modified versions and forks. Cairn's project policy
is that they use a distinct name and visual identity unless Mason gives written
permission.

A fork may accurately say that it is "based on Cairn Linux" and link to this
project. Its own name should be more prominent, and it should not use the
stacked-stones mark as its product mark.

## The visual mark

When this policy or written permission allows use of the mark:

- use a generated file from `brand/` without changing its shape;
- preserve its clear space and proportions;
- do not add a face, outline, gradient, rotation, or decoration; and
- follow the contrast and colour rules in [`brand/README.md`](brand/README.md).

The design tokens, type scale, and layout patterns remain available under
CC BY-SA 4.0 as described in the repository.

## The word "Linux"

"Linux" is a registered trademark of Linus Torvalds. Cairn's use of that word
does not grant anyone else rights in the Linux mark. The project has not yet
applied to the Linux Mark Institute for a sublicence; that is issue #21.

## Questions and permission requests

Open a GitHub issue if you are unsure whether a proposed public use needs
permission. Do not post private contracts, addresses, account details, or
credentials in an issue.
