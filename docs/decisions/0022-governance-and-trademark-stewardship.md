# ADR-0022: Governance and trademark stewardship

**Status:** accepted
**Date:** 2026-09-30

## Context

Cairn needed a public record of who makes project decisions, how contributors
retain copyright, and who controls the project name and accounts. Pull request
#93 added `GOVERNANCE.md`, `TRADEMARKS.md`, and the matching licence and
contribution clarifications.

That pull request was prepared by an AI agent and merged before the human
maintainer's Developer Certificate of Origin sign-off was recorded.

## Decision

Mason Ball has reviewed and ratifies the documentation introduced by commit
`a2d9cb4d36e4ac75481ddf3de7b5326c847a5c61`. He accepts responsibility for
submitting it and certifies the Developer Certificate of Origin for that
contribution.

`GOVERNANCE.md` and `TRADEMARKS.md` are the current project policies. Future
AI-assisted contributions require a human DCO sign-off before merge.

## Consequences

The repository has a durable human attestation for the governance contribution
without rewriting published history. This does not change any contributor's
copyright or the rights granted by the existing project licences.
